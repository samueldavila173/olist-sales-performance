## Visualización de resultados | Power BI

Una vez preparado el análisis en SQL, conecté los resultados con Power BI para crear un dashboard interactivo.

El informe permite explorar la evolución mensual de las ventas, comparar las categorías de productos y filtrar los resultados por año y mes.
